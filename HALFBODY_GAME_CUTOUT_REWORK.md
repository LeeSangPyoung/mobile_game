# Halfbody Game Cutout Rework

Transparent game cutouts must have no fire, no smoke, no glow field, and no decorative atmosphere baked into the image. The final game asset must be a transparent PNG that can sit naturally over any battle or UI background.

The source halfbody image is an identity/style reference, not the final in-game file:

- Source pattern: `assets/generals/new_characters/upper_body_200_redraw_v6_above_navel/{id}_halfbody_redraw_v6.png`
- Current new-halfbody pattern: `assets/generals/new_characters/upper_body_200_redraw_v9_new_halfbody/{id}_halfbody_game_cutout_v9.png`
- Review page: `new_generals_halfbody_game_cutout_v2_hardmask_200.html`
- Main comparison page: `new_generals_halfbody_recovered_200_v6_progress.html`

## Acceptance Rules

- Final file must be PNG with alpha transparency.
- Character must remain the same person as the v6 halfbody reference.
- Preserve face, headwear, hair, beard, armor category, palette, pose attitude, and upper-body framing.
- Pose and expression should be re-composed for a halfbody portrait. Preserve identity and character attitude, but do not clone the fullbody pose or expression; otherwise the asset is just a fullbody crop.
- Do not accept a formal ID/passport-photo read: no static front-facing symmetry, no straight vertical robe silhouette, no neutral encyclopedia portrait, and no generic scroll-plus-raised-hand pose when it weakens the character attitude.
- The halfbody should use an intentional portrait action: angled shoulders, three-quarter torso, diagonal prop/weapon/fan/scroll line, expressive hand placement, or a clear command gesture that gives the game cutout energy at review size.
- Remove all baked background: fire, sparks, embers, smoke, glow clouds, vignette, floor light, and texture.
- Keep only character-attached lighting that reads as painted edge highlight on armor/hair, not a separate aura.
- Edges should be clean on dark, light, checker, and actual battle backgrounds.
- Do not crop crown tips, hair, shoulders, sleeves, hands, cape edges, or lower torso details that are already visible in the source.
- If a hat, hair tip, elbow, hand, weapon, bow, quiver arrow, cape edge, or shoulder ornament is cut by the source frame or by generation, redraw/extend the missing part inside the canvas instead of leaving it clipped.
- This applies even when the source v6 image is already cropped. Do not accept a hardmask that preserves a cropped sleeve, hat, tassel, hand, shoulder, fur collar, cape, weapon, or side ornament.
- A bottom crop is acceptable only when it is a deliberate clean waist/torso crop. Sleeves, hands, elbows, cape folds, tassels, weapons, and side ornaments must not be cut by the bottom or side edges.
- The image must read as a true halfbody/upper-body asset at review size, not a small fullbody character. Any visible foot, boot, knee, long leg silhouette, or full-length robe/skirt stance is a rejection even when the alpha is clean.
- The torso should be enlarged enough that face, shoulders, chest armor, hands, and waist details are the dominant read.
- Do not leave small floating fragments from cropped props; either complete the prop inside the frame or remove/recompose it cleanly.
- Do not overwrite the source `redraw_v6` files.

## 2026-06-04 Direction Reset

- The v7 strict pass is rejected as a production direction. It is a deterministic crop/reframe of the fullbody cutouts, so it can still look like a cropped fullbody and can leave hard lower torso/cape/ornament cuts.
- New accepted direction: make each character as a new halfbody portrait illustration, one at a time, on removable chroma key, then convert to transparent PNG.
- Pose and expression are allowed and expected to change when that improves the halfbody read. Keep identity, faction palette, headwear, hair/beard, armor language, and character attitude.
- Style balance baseline: use `guan_yu` v9 first style-match redraw as the current reference balance. The later babyfied redraw is rejected as a direction. Match the accepted fullbody SD/chibi game set without drifting into either extreme: not a hyper-detailed premium portrait, and not an over-babyfied toy face. Keep mature/heroic character attitude, rounded game proportions, readable chunky armor, moderate detail density, and the same material/lighting family as the fullbody cutouts.
- Active composition anchors: use the first four reviewed generals (`cao_cao`, `cao_xing`, `dian_wei`, `dong_zhuo`) plus `gan_ning` and the restored first-style-match `guan_yu` as the live pose/composition reference set. These anchors show the target game-cutout energy: clear character action, readable hands/props, angled shoulders, strong lower torso finish, and no formal ID-photo staging.
- Restart point: after restoring the `guan_yu` first style-match baseline, regenerate from `guo_jia` onward one character at a time. Existing drafts from `guo_jia` onward must not be treated as approved production direction until they are redrawn or re-audited against this baseline.
- Do not mark a character `Passed` until visual approval. Use `Review` for newly generated drafts.
- Current reviewed drafts: rows 001-130 are in `Review` up through `zhuge_dan`, with `liu_ye` and `kuai_liang` at v10 and the rest v9 unless noted in the table. Treat newly generated drafts as visual-review only until user approval. All rows from `zhang_yi_shu` onward are rejected/restart placeholders until regenerated one 10-character batch at a time. Next target after user feedback: `zhang_yi_shu`.
