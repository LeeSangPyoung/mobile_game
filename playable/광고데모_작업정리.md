## 2. 광고 시나리오 (실제 동작, 단계별)

무대: 중앙에 중립 공성(낙양), 위쪽 좌·우에 적성 2개(호뢰관=여포, 업성=동탁), 아래에 아군 본성(성도=유비, 압도적 병력 95창).

1. **로딩** — 승리배경 + "손가락 삼국지" 타이틀 + 스피너 (옛날 main.png 안 씀)
2. **공성 단계** — 손가락 👆가 성도→낙양(공성)으로 드래그 가이드. 유저가 조준 성공하면 손가락 사라짐 → 낙양 점령
3. **왼쪽 적(여포)** — 아군 병력이 **전부 성에 복귀·집결한 뒤**에야 손가락 가이드 등장(집결 전엔 "병력 집결 중…"). 조준 성공 시:
   - 손가락 사라짐
   - **조준당한 여포가 장수를 이끌고 즉시 반격 출진(sallyEnemy)** — 공격이 들어온 성(출발지) 방향으로
   - 왼쪽만 반격, 오른쪽(동탁)은 봉인
4. **오른쪽 적(동탁)** — 여포 함락 후 같은 방식. 조준 성공 시 동탁 봉인 해제 + 출진
5. **CTA(엔드카드)** — 승리배경 위에:
   - "손가락 삼국지" 큰 금색 타이틀(한 줄) + "천하통일! · 유비·관우·장비와 천하를"
   - 특징 칩: 🏯 방대한 시나리오(작게) / **⚔ 장수 수집·강화**(금색 큰) / **👥 실시간 멀티·친구대전**(제일 큰 금색+글로우)
   - "무료로 설치하고 시작 ▶" 버튼 (클릭 → `ExitApi.exit()` → 스토어)
   - 하단 "무료 설치 · 삼국 실시간 전략" (★별점 절대 넣지 말 것 — 가짜평점)

**설계 원칙: 아군은 항상 이긴다.** 트릭이 아니라 **압도적 병력**(성도 창95 + lv30 장수)으로. 적은 약한 소수. (유저 명시 요구)

## 3. 어떻게 만들어지나 (아키텍처)

플레이어블 = `prototype.html`(실제 게임 44k줄) + `inject.txt`(광고 로직) + **자산/폰트 인라인**.

- **`inject.txt`** = 광고 로직 전부. `</body>` 앞에 주입됨. 전역 함수를 `window.foo=...`로 오버라이드해 게임을 광고 모드로 몰고 감. **웹 빌드(game-showcase)와 플레이어블 빌드가 이 파일을 공유**한다.
- **`build_playable.js`** = 조립기. prototype에 아래 적용:
  1. `@font-face` 3개 → data URI (NotoSerifKR 재subset + 장식폰트 2종)
  2. `roster_200.js` 외부 스크립트 인라인
  3. **shim**(`<head>` 최상단, 최초 실행): 이미지 `src`를 인라인 data URI로 가로챔 / 매핑없는 자산 → 투명픽셀 / **WebSocket·fetch·XHR·Audio 전부 차단**(네트워크 0)
  4. `inject.txt` 주입
  5. 최종 HTML의 모든 `assets/*` URL 일괄 치환
  6. 승리배경은 CSS 변수 `--advic`로 **1벌만**(로딩+CTA 공유)
- **`compress.js`** = 광고가 실제 쓰는 자산만 webp로 재압축 → `assets_inline.json`
- **`verify_offline.js`** = 네트워크 전면차단 상태에서 정상 구동 검증

## 4. 재빌드 (다른 PC에서)

```bash
cd mobile_game/playable/build
npm install                 # puppeteer-core (로컬 Chrome 필요)
node build_playable.js      # → ../playable_ad.html (대부분 이것만)
node verify_offline.js      # CTA:true / JS에러:0 / 차단네트워크:0 이어야 정상

# 자산 바꿨을 때만: node compress.js  (Chrome로 webp 재인코딩)
# 폰트 글자셋 바꿨을 때만: pyftsubset (아래)
python -m fontTools.subset ../../assets/fonts/NotoSerifKR-subset.woff2 \
  --text-file=glyphs_all.txt --output-file=NotoSerifKR-ad.woff2 \
  --flavor=woff2 --layout-features='*' --no-hinting
```
`CHROME_PATH` 환경변수로 Chrome 경로 지정 가능.

## 5. 반드시 지킬 것 · 지뢰 (이거 어기면 또 터진다)

### 5-1. 장수 얼굴 = `war_v6` 아이콘 (faces/ 아님!) — 가장 크게 헛발질했던 부분
- 성 배지가 그리는 얼굴은 `generals/faces/{id}.png`가 **아니라**
  `generals/face_icons/war_v6_halfbody_style_transparent/{id}_war_face_icon_v6_cute50.png` 이다. (`battleFaceIconSrc()` 참고, 200명 전부 V6)
- `compress.js`는 주요 장수(=faces/ 보유 id) 54명분 **war_v6**를 인라인한다.
- **얼굴이 빈 원으로 뜨면** → 그 장수 id의 war_v6가 맵에 없는 것. `compress.js` 대상에 추가.
- 주의: 매핑없는 자산을 shim이 **투명픽셀로 반환**하는데, 투명픽셀은 "로드 성공"이라 엔진의 faces/ 폴백(onerror)이 **안 터진다**. 그래서 그냥 빈 원이 됨.

### 5-2. network-0 필수 (Google Ads 플레이어블 정책)
- shim이 이미지/WebSocket/fetch/XHR/Audio 전부 차단. `verify_offline.js`로 **차단 네트워크 0** 항상 확인.
- 오디오는 정책상 무음이어야 하므로 `window.Audio`도 스텁.

### 5-3. `showTutoDrag`는 광고·본게임 튜토리얼 **공용**
- `prototype.html`의 이 함수를 고치면 **광고에도 딸려 들어간다** (실제로 이중 손가락 터졌었음).
- 광고 전용 동작은 `if (window._adMode) return;`로 막을 것. `_adMode`는 `inject.txt` 상단에서 `AD||SHOW`로 세팅.
- 손가락 모션은 광고 = `👆`(adFinger, cyc 1500·3구간). 본게임 튜토리얼도 **같은 👆**(tutoAdFinger)를 쓰도록 통일함.

### 5-4. 구형 안드로이드 웹뷰 호환
- `?.`·`??`·`ctx.roundRect` 직접호출 **금지**(성 안그려짐/멀티 먹통). prototype.html에 roundRect 폴리필 + 문법 치환 되어 있음. 광고 코드에도 동일 규칙.

### 5-5. 크기 여유
- 현재 3.76MB. 승리배경을 `--advic`로 1벌만 넣어 4.64→3.76 줄임. 성 스프라이트는 정적 리터럴(`CASTLE_SPRITE_ASSETS`)로 캔버스에 로드되므로 **투명치환 금지, data URI 유지 필수**.

## 6. 이번에 고친 버그들 (다시 만들지 말 것)
- 옛날 성 이미지가 3초 후 현재로 바뀜 → 스프라이트 프리로드 대기(procedural 강제 금지, 그게 오히려 옛날 이미지였음)
- 메뉴/제목/챕터 배너 번쩍임 → goToMenu·showChapterTierBanner 즉시 no-op 오버라이드 + CSS hide
- 여포한테 짐 → 아군 압도적 병력으로 단순화(트릭 X)
- **배속 3배 넣었다가 유저 대노** → 배속 금지, 자연 속도(`window._marchMul=1`). 절대 다시 배속 넣지 말 것
- 옛날 main.png("성따먹기") 로딩/CTA에서 제거 → 승리배경으로
- 얼굴 빈 원 → war_v6 인라인(5-1)
- 이중 손가락 → `_adMode` 게이트(5-3)

## 9. Google Ads 등록 (현황)
등록처 = **Google Ads 앱 캠페인**(AdMob 콘솔 아님). 올린 소재가 AdMob 네트워크에 전면광고로 노출됨.

사전준비 점검:
- ✅ 앱 Play 게시: "손가락 삼국지 : 실시간 전략 대전" (`com.leesp.samgukgi`)
- ✅ 설치 전환추적: 앱 연결 시 Google Play 설치 자동추적(Firebase 불필요) → 설치수 캠페인 즉시 가능
- ⚠️ 인앱 이벤트(Firebase/GA4): 미설정 → "설치 후 행동" 최적화 원할 때만 필요
- ❓ Google Ads 계정: 유저 확인 필요

주의: **HTML5(플레이어블) 소재 업로드는 계정 지출이력/지원요청으로 활성화**해야 하는 경우가 많음. 신규 계정은 텍스트+이미지+동영상 먼저 → HTML5 요청.
