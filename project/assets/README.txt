assets/
========

이 폴더에 PNG 파일을 넣으면 script.js가 자동으로 로드해서
해당 [data-img] 요소의 background-image로 적용합니다.

기대 파일 (없어도 동작 — CSS placeholder fallback):

  avatar_lord.png       프로필 아바타 (40x40)
  icon_gold.png         재화 아이콘 (20x20)
  icon_gem.png          재화 아이콘 (20x20)
  bg_main.png           메인 배경 (430x360)
  char_guanyu.png       장수 카드 (86x143)
  char_cao.png          장수 카드 (86x143)
  char_zhuge.png        장수 카드 (86x143)
  btn_start.png         출정 버튼 (320x70)
  panel_pvp.png         모드 카드 (78x100)
  panel_tower.png       모드 카드 (78x100)
  panel_guild.png       모드 카드 (78x100)
  nav_hero.png          하단 탭 아이콘 (24x24)
  nav_formation.png     하단 탭 아이콘 (24x24)
  nav_battle.png        하단 탭 중앙 (50x50)
  nav_territory.png     하단 탭 아이콘 (24x24)
  nav_bag.png           하단 탭 아이콘 (24x24)

파일을 추가하면 새로고침만 하면 자동 적용됩니다.
