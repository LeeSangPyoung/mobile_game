# 가속 컷(*_swing) 발주 대상 — 측정 기준

## 왜 전원에게 안 넣는가

가속 컷은 **원래 프레임 간 점프가 컸던 기술에만 값이 있다.** 여포·태사자
두 명으로 켬/끔을 재 보니 패턴이 분명했다.

    기술          점프(끔) → 점프(켬)      판정
    여포 강베기     11.0  →  5.5          절반. 크게 개선
    여포 베기        9.0  →  4.4          절반. 크게 개선
    여포 찌르기      3.3  →  4.1          오히려 나빠짐
    태사자 베기      6.5  →  4.1          조금 개선
    태사자 강베기    3.9  →  3.8          변화 없음

원래 점프가 작은 기술(찌르기처럼 곧게 뻗는 동작)은 중간에 다른 자세를
끼우면 오히려 새 점프를 만든다. **기준 8.0** 이 두 사례와 정확히 맞는다.

## 재는 법

    node /tmp/jumps.mjs        # 전 장수 × 3기술의 최대 프레임 점프

화면 무게중심이 연속 프레임 사이에 얼마나 튀는지를 잰다. 가속 컷을 끈
상태(POSE_SET[key][3] = null)로 재야 '지금 얼마나 나쁜가'가 나온다.
