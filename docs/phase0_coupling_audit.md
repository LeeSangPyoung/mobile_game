# Phase 0 · 상수 전수감사 결과 (시뮬 뷰포트/난수/시계 결합)

읽기전용 감사 산출물. **줄번호는 ±1 오차 가능**(편집 시 실제 매칭). 대상: 시뮬 함수 `sendArmy`(19143)~`checkWin`(20420) + 헬퍼.

> 결론: 결합 지점이 **경계된 목록**으로 확정됨. 대략 **좌표/DPR 47 · 줌 7 · 시뮬난수 15 · 시뮬시계 4**.
> **연출용(난수 13 · 시계 14)은 절대 건드리지 않는다**(§4).

## 진행 상황

  시뮬 사거리/속도/합류/점령/회피 상수의 `DPR()`→`SIM_DPR(1.5)`. **부대 위치 47개 사이트는 worldPxW/H 경유라 자동 반영.**

- **Step 2 (완료·QA대기)** — B 카테고리 `/zoom` 제거 → 사거리·속도·거리 고정 월드상수(줌-독립). 줌이 게임성 바꾸던 버그 제거.
  - `dist()`를 스크린공간(`cx/cy`, 줌·카메라 포함)에서 **월드픽셀**(`(a.x-b.x)*worldPxW` 등)로 전환.
  - 게임영향 10곳 `/zoom` 제거: `dist`·`ENGAGE_DIST`·`ATTACK_RANGE`·`AGGRO_DIST`·`SHOOT_RANGE`·합류·점령·이동속도·도착·분열스폰.
  - **연출 입자/데미지텍스트/화살흩뿌림의 `/zoom`은 의도적 유지**(렌더에서 `*zoom` 되어 화면 고정, §C-cosmetic).

## 0. 근본 원인 — 좌표계

- 부대 `army.x/y` = `정규화 × worldPxW()/worldPxH()` (= "월드픽셀" 공간).
- `worldPxW() = worldW × max(W, 360×DPR())` → **캔버스 폭 W + DPR 종속**. `worldPxH() = worldH × H`.
- 거리비교가 두 종류로 섞임: ① `dist()`=`cx/cy`(줌·카메라 포함 **스크린공간**) ② `a.x - target.x*worldPxW()`(**월드픽셀공간**, 줌 제외). 여기에 사거리는 `RANGE×DPR()/zoom`으로 비교 → **일관성 붕괴**.

**목표**: 단일 **고정 월드단위**(DPR·줌·캔버스 무관). `worldPxW/H`를 고정 기준치로, 사거리·속도는 고정 상수로, 렌더(cx/cy/w2sx/w2sy)만 줌·카메라·DPR 적용.

## 전환 전략 (권장 순서, 증분)

1. **`worldPxW()/worldPxH()`를 고정 기준치로** (예: `worldW × REF_W`, REF_W=상수). → 시뮬 좌표에서 **DPR·캔버스 W 제거를 한 곳에서** 달성. 렌더 cx/cy는 그대로 줌·카메라 적용.
2. **`dist()`를 월드단위로** + B의 `/zoom` 전부 제거, 사거리 상수에서 `*DPR()` 제거 → **고정 월드상수화**.
3. **속도/임계 상수**(20106,20117,20134,20150) `*DPR()`·`/zoom` 제거.
4. 매 단계 **싱글 QA**(부대 조우/공성/점령/속도 이전과 동일 체감). 카메라 minZoom/clampCamera 재조정 필요할 수 있음(렌더측).
5. **C(15)** seed rng로, **D(4)** 누적dt/틱으로 — 결정론 self-test.

**리스크 완화**: `feature/mp-phase0` 브랜치 + 커밋 복원점. 단계마다 커밋.
