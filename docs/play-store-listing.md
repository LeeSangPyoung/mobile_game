## 3. 전체 설명 (Full description, ≤4000자)

```
■ 손가락 하나로 펼치는 삼국지 실시간 점령 전략

성을 탭하고, 병종을 고르고, 적 성으로 부대를 보내세요.
복잡한 조작 없이 손가락 터치만으로 전장을 지휘하는 가볍고 쫄깃한 실시간 전략(RTS)입니다.

■ 핵심 재미

· 실시간 성(城) 점령전 — 모든 적 성을 빼앗으면 승리. 한 판 5분 내외로 빠르게.
· 병종 상성의 묘미 — 창 > 기병 > 궁병 > 창. 상성을 맞추면 전투력 1.5배. 머릿수보다 머리싸움.
· 200명의 삼국지 무장 — 조조·유비·관우·여포·제갈량부터 숨은 명장까지. 수집하고 편성하세요.
· 천(天)·지(地)·인(人) 포메이션 — 나만의 출진 조합을 미리 짜두고 전장에 투입.
· 회유(귀순) 시스템 — 운이 따르면 적 부대가 내 편으로! 전세를 단숨에 뒤집는 한 수.
· 장수 강화 & 전투력 관리 — 별을 모아 장수를 키우고, 성·병력을 업그레이드.

■ 방대한 캠페인 + 엔드게임

· 10개 챕터, 200개 스테이지로 점점 거세지는 난이도.
· 챕터가 오를수록 적은 강해지고 전장은 넓어집니다 — "약한 적 물량"에서 "강적 정예"까지.
· 무한 모드 — 끝없이 상승하는 도전. 오직 성장과 전략으로 돌파하세요.

■ 가볍고 깔끔하게

· 완전 오프라인 플레이 — 인터넷 없이 즐기세요.
· 광고 없음, 인앱결제 없음.
· 개인정보 수집 없음 — 모든 기록은 내 기기에만 저장.

지금 출진하여 천하를 통일하세요!
```

## 6. 개인정보처리방침 URL (필수)

`docs/privacy-policy.md` 작성 완료. **호스팅 필요** — 가장 쉬운 방법:

1. GitHub 저장소 → Settings → Pages → Source: `main` 브랜치 `/docs` 폴더 선택
2. 생성 URL 예시: `https://leesangpyoung.github.io/mobile_game/privacy-policy`
   (md를 html로 자동 변환하려면 `/docs`에 간단한 변환 또는 privacy-policy.html 추가 권장)

→ 이 URL을 Play Console "개인정보처리방침" 및 데이터안전에 입력.
