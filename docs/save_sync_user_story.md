# 유저는 무엇을 겪는가 — 장면으로 쓴 시나리오

[설계](save_sync_design.md) · [테스트](save_sync_test_scenarios.md) 의 짝.
코드가 아니라 **사람이 겪는 일**만 적는다.

> 2판. 1판은 유저가 「계정 연결」 버튼을 누르는 방식이었다.
> 지금은 **구글 플레이 게임즈 자동 로그인** 이라 누를 것이 없다.

---

## 장면 1. 민수 — 어제 깐 사람 (신규)

민수는 어제 앱을 깔았다. 오늘 20장을 깼다.

승리 화면이 뜨고, 별 3개가 찍히고, 골드가 들어온다. 그리고 **딱 한 번** 이게 뜬다.

```
   ┌────────────────────────────────┐
   │   기록이 안전하게 보관됩니다    │
   │                                │
   │   구글 계정에 연결되어 있어     │
   │   폰을 바꾸거나 앱을 지워도     │
   │   그대로 이어서 할 수 있습니다. │
   │                                │
   │           [ 확인 ]              │
   └────────────────────────────────┘
```

민수가 할 일은 **[확인]** 을 누르는 것뿐이다. 연결하라는 요청이 아니라,
**이미 되어 있다는 알림**이다. 평생 다시 안 뜬다.

> 민수가 앱을 처음 켰을 때 플레이 게임즈가 폰의 구글 계정으로 조용히
> 로그인했다. 민수는 그때는 몰랐고, 지금 알았다.
> 두 달 뒤 폰을 바꿀 때 이 한 줄을 기억하느냐가 갈림길이 된다.

---

## 장면 2. 민수, 두 달 뒤 — 폰을 바꿨다

45장까지 갔다. 장수 80명, 여포가 다이아 만렙이다.

새 폰에 앱을 깐다. 연다.

```
   (로딩)

   45장 12절 — 이어서 하기
```

**끝이다.** 민수가 한 일은 앱을 깐 것뿐이다.

같은 구글 계정을 쓰는 폰이니 플레이 게임즈가 알아서 같은 사람으로 알아본다.
장수 80명, 여포 다이아 만렙, 별 340개 그대로다.

> 지금은 여기서 튜토리얼이 시작된다. 그래서 한 명이 그만뒀다.

## 장면 3. 영희 — 20챕터 진행 중 (기존 유저)

이미 400장 넘게 깬 사람.

### 업데이트 받은 날

Play 에서 업데이트가 뜬다. 받는다. 연다.

```
   (평소와 똑같은 시작 화면)
   20챕터 7절 — 이어서 하기
```

**아무 일도 없다.** 팝업도, 로딩도, 로그인 화면도 없다. 어제 하던 그 자리다.

> 뒤에서는 영희의 400장 기록이 조용히 서버로 올라간다. 서버가 비어 있었으니
> **충돌이 날 수가 없다.** 로컬 기록이 그대로 사본이 된다.
> 플레이 게임즈도 조용히 로그인해서, 그 기록이 영희 것으로 묶인다.

### 영희도 한 번은 듣는다

메인 화면으로 나오면 딱 한 번 뜬다.

```
   ┌────────────────────────────────┐
   │   기록이 안전하게 보관됩니다    │
   │                                │
   │   구글 계정에 연결되어 있어     │
   │   폰을 바꾸거나 앱을 지워도     │
   │   그대로 이어서 할 수 있습니다. │
   │                                │
   │           [ 확인 ]              │
   └────────────────────────────────┘
```

영희는 400장을 깬 사람이다. **가장 잃을 게 많은 사람**이라 이 한 번이 중요하다.
[확인] 누르면 끝이고, 다시는 안 뜬다.

> 조건을 "1챕터 클리어" 로만 잡으면 영희에게는 영영 안 뜬다.
> 이미 한참 전에 깼기 때문이다. 그래서 기존 유저는 따로 잡는다.

### 나중에 영희 폰이 고장나면

새 폰에 앱을 깐다. **20챕터 7절 그대로.**

---

## 장면 4. 철수 — 앱을 지웠다 다시 깔았다

용량이 없어서 지웠다. 며칠 뒤 생각나서 다시 깐다.

```
   12챕터 3절 — 이어서 하기
```

철수는 아무것도 안 했다.

> 두 겹으로 막힌다. 플레이 게임즈가 같은 계정을 알아보고, 설령 그게 안 되어도
> 토큰이 안드로이드 네이티브 저장소에 한 벌 더 있어 자동 백업이 챙긴다.

---

## 장면 5. 지훈 — 두 대를 번갈아 쓴다

집에 태블릿, 밖에선 폰. 둘 다 같은 구글 계정이다. **따로 설정한 것 없다.**

지하철에서 폰으로 13장을 깼다. 집에 와서 태블릿을 켠다.

```
   13장 20절 — 이어서 하기
```

바로 이어서 한다.

### 갈라졌을 때 (드문 경우)

비행기 모드로 폰에서 15장, 태블릿에서 14장을 따로 진행했다면 —
**말없이 하나를 죽이지 않는다.** 고르게 한다.

```
   이어서 할 기록을 고르세요

   ┌─ 이 기기 ────────┐   ┌─ 다른 기기 ──────┐
   │  14장 5절         │   │  15장 20절        │
   │  장수 34명        │   │  장수 36명        │
   │  오늘 14:02       │   │  오늘 21:30       │
   │    [ 이걸로 ]     │   │    [ 이걸로 ]     │
   └──────────────────┘   └──────────────────┘

   고른 쪽으로 시작합니다. 다른 기록도 7일간 보관됩니다.
```

두 기기를 **오프라인으로** 번갈아 써야 나오는 화면이다. 대부분은 평생 못 본다.
그래도 있어야 한다 — 없으면 그때 조용히 한쪽이 죽는다.

## 장면 6. 소수 — 플레이 게임즈가 없는 사람

플레이 게임즈를 꺼 뒀거나, 구글 서비스가 없는 기기.

이 사람은 자동 로그인이 안 된다. **게임은 평소대로 된다.** 다만 기록이
그 폰에만 남는다(지금과 같다).

설정에 들어가면 이게 있다.

```
   계정
   ────────────────────────
   상태      이 기기에만 저장됨
   [ 구글 계정으로 연결 ]
   [ 복구 코드 보기 ]
```

원하면 직접 연결한다. 안 해도 그만이다.

이 사람에게는 **알림이 아니라 요청**이 뜬다. 실제로 누를 것이 있기 때문이다.

```
   ┌────────────────────────────────┐
   │   ⚠ 기록이 이 폰에만 있습니다   │
   │                                │
   │   폰을 바꾸거나 앱을 지우면     │
   │   처음부터 시작하게 됩니다.     │
   │                                │
   │   [ 구글 계정으로 연결 ]        │
   │   [ 나중에 ]  [ 다시 보지 않기 ] │
   └────────────────────────────────┘
```

「나중에」면 다음 기회에 또 묻고, 「다시 보지 않기」면 끝이다.

## 그래서 달라지는 것

| | 지금 | 만든 후 |
|---|---|---|
| 앱 켜기 | 그대로 | **그대로** |
| 게임 화면·조작 | 그대로 | **그대로** |
| 로그인 화면 | 없음 | **없음** |
| 팝업 | 없음 | **평생 1회 안내** ([확인] 하나) |
| 폰 바꿈 | 처음부터 | **이어서** |
| 앱 지웠다 깜 | 처음부터 | **이어서** |
| 폰 고장·분실 | 끝 | **이어서** |
| 두 기기 같이 | 불가 | **가능** |
| "기록 날아갔어요" 문의 | 해 줄 게 없음 | **찾아서 돌려줌** |

**유저가 하는 일은 [확인] 한 번뿐이다.**
평소엔 티가 안 나고, **폰이 바뀌는 날에만** 티가 난다.
