# War Face Icons v6 Halfbody Style

Date: 2026-05-31

## Direction

The selected direction is `cute50` with a transparent background.

Use this for war-mode representative face icons:

- The current v6 half-body image is the primary target for both identity and rendering style.
- Accepted face icons such as Cao Cao, Cao Xing, Xu Chu, Dian Wei, and Gan Ning are framing/scale references only. Do not copy their smoother or different rendering style onto a character whose half-body uses a heavier textured style.
- Final accepted assets must be newly drawn/generated face icons, not deterministic crops from halfbody/fullbody art.
- Face-only square icon.
- Based on each general's current v6 halfbody/fullbody identity and matching that half-body's drawing/rendering style.
- Serious battle expression, but with a collectible and approachable feel.
- Cute enough to soften the grim expression, not so cute that the general becomes a baby, mascot, or comedy character.
- Keep each general's core identifiers: hair, facial hair, crown/helmet/headband, faction colors, and expression silhouette.
- Strict war face icon means head, face, hair, facial hair, headgear, neck, and only the very top shoulder/collar/scarf line as a small framing cue. Stop above the chest. Do not include torso, chest plate, large shoulder armor, hands, or weapons.
- No visual background. Final icons must be PNGs with alpha transparency.
- Do not use smoky, fiery, dark, gradient, or atmospheric backgrounds in final assets.

## Restart Lessons Learned

The 2026-06-09/2026-06-10 restart pass tightened the rule beyond the older Huang Gai-only audit:

- The half-body image is the identity and art-style anchor. The final face icon must read as the same person and the same rendering style first, then as the shared 256x256 neck-only icon format second.
- Existing accepted icons are only framing references: large face, neck-only bottom, transparent corners, and no body mass. They are not a license to redraw the character in a smoother, flatter, or different cute50 sub-style.
- Do not solve identity mismatch by cropping the half-body art. Final assets must still be newly drawn/generated face icons.
- Do not redesign the character while chasing polish. Preserve face shape, age read, eyes, eyebrows, facial hair, headgear, hair silhouette, and signature ornaments from the half-body reference.
- Expression changes are allowed and useful for game readability, but only within the existing identity. Change the mouth/energy/eye intensity, not the haircut, skull shape, beard type, headgear, or age.
- When differentiating similar characters, avoid sly/winking/villain expressions unless the half-body identity already supports it. Prefer noble smile, battle shout, focused glare, or confident grin.
- The neck-only frame now means head, hair, facial hair, headgear, visible neck, and at most a hair-thin collar/scarf cue. No shoulder armor, chest, hands, weapons, broad scarf mass, or torso.
- For green-heavy characters such as Guan Yu, use magenta chroma key rather than green before alpha removal.
- Candidate sheets must be compared against both the half-body identity and the current accepted icons. Do not promote a candidate just because it is pretty.
- For relay batches, make a before/after sheet and inspect same-person read, expression variety, center placement, lower-corner alpha, and neck-only crop before touching the gallery version.
- Reject candidates that look like a different game, even if the character identifiers are technically present. Matching cap, jewel, beard, or colors is not enough if the surface texture, face sculpt, and overall rendering do not match the half-body.
- After promotion, verify that the active PNG equals the selected candidate by hash or pixel comparison, and bump the gallery cache version so the browser cannot show a rejected older face.
- Keep rejected but informative attempts in backup/candidate folders and document why they failed, so the same mistake is not repeated later.
- 2026-06-11 relay lesson: for long batches, process in 10-character sheets and self-reject before promotion when a candidate adds a second crown/jewel, changes a clean-shaven character into a bearded one, turns a compact guard ornament into a tall official crown, or shifts female icons into a separate realistic portrait style.
- 2026-06-11 alpha lesson: green chroma-key residue can remain on red/green ornament edges after connected-background removal. The relay processor now also clears bright green fringe when the sampled key is green; reprocess the batch source before accepting if any corner or ornament edge shows key color.

As of the 2026-06-03 redraw audit, all previous `crop` fallback entries are placeholders only. They must be regenerated from scratch in the Huang Gai-style face-only cute50 direction before they count as complete.

## Postprocess

Remove chroma key, then downscale final transparent icons to 256x256:

```bash
python3 "${CODEX_HOME:-$HOME/.codex}/skills/.system/imagegen/scripts/remove_chroma_key.py" \
  --input tmp/war_face_icons_v6_chromakey/{id}_war_face_icon_v6_cute50_chromakey.png \
  --out assets/generals/face_icons/war_v6_halfbody_style_transparent/{id}_war_face_icon_v6_cute50_source.png \
  --auto-key border \
  --soft-matte \
  --transparent-threshold 12 \
  --opaque-threshold 220 \
  --despill
```

```bash
sips -z 256 256 \
  assets/generals/face_icons/war_v6_halfbody_style_transparent/{id}_war_face_icon_v6_cute50_source.png \
  --out assets/generals/face_icons/war_v6_halfbody_style_transparent/{id}_war_face_icon_v6_cute50.png
```

Validate alpha:

```bash
sips -g hasAlpha -g pixelWidth -g pixelHeight \
  assets/generals/face_icons/war_v6_halfbody_style_transparent/{id}_war_face_icon_v6_cute50.png
```

For very tight crops where the subject touches the border, do not use `--auto-key border`; explicitly pass `--key-color '#00ff00' --auto-key none`, otherwise the tool can sample the crown/hair instead of the green background.

For green-heavy characters such as `guan_yu`, use a magenta chroma key instead of green:

```text
Create the subject on a perfectly flat solid #ff00ff chroma-key background.
Do not use #ff00ff anywhere in the subject.
```

Then remove it with:

```bash
python3 "${CODEX_HOME:-$HOME/.codex}/skills/.system/imagegen/scripts/remove_chroma_key.py" \
  --input tmp/war_face_icons_v6_chromakey/{id}_war_face_icon_v6_cute50_chromakey.png \
  --out assets/generals/face_icons/war_v6_halfbody_style_transparent/{id}_war_face_icon_v6_cute50_source.png \
  --key-color '#ff00ff' \
  --auto-key none \
  --soft-matte \
  --transparent-threshold 18 \
  --opaque-threshold 180 \
  --despill \
  --force
```
