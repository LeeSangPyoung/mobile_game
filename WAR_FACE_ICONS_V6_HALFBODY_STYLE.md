# War Face Icons v6 Halfbody Style

Date: 2026-05-31

## Direction

The selected direction is `cute50` with a transparent background.

Use this for war-mode representative face icons:

- Huang Gai is the confirmed practical target for framing and finish.
- Final accepted assets must be newly drawn/generated face icons, not deterministic crops from halfbody/fullbody art.
- Face-only square icon.
- Based on each general's current v6 halfbody/fullbody identity.
- Serious battle expression, but with a collectible and approachable feel.
- Cute enough to soften the grim expression, not so cute that the general becomes a baby, mascot, or comedy character.
- Keep each general's core identifiers: hair, facial hair, crown/helmet/headband, faction colors, and expression silhouette.
- Strict face icon means head, face, hair, facial hair, headgear, and visible neck only. Do not include chest, shoulders, armor, collar, torso, hands, or weapons.
- No visual background. Final icons must be PNGs with alpha transparency.
- Do not use smoky, fiery, dark, gradient, or atmospheric backgrounds in final assets.

As of the 2026-06-03 redraw audit, all previous `crop` fallback entries are placeholders only. They must be regenerated from scratch in the Huang Gai-style face-only cute50 direction before they count as complete.

```bash
python3 "${CODEX_HOME:-$HOME/.codex}/skills/.system/imagegen/scripts/remove_chroma_key.py" \
  --input tmp/war_face_icons_v6_chromakey/{id}_war_face_icon_v6_cute50_chromakey.png \
  --out assets/generals/face_icons/war_v6_halfbody_style_transparent/{id}_war_face_icon_v6_cute50_source.png \
  --auto-key border \
  --soft-matte \
  --transparent-threshold 12 \
  --opaque-threshold 220 \
  --despill
```

```bash
sips -z 256 256 \
  assets/generals/face_icons/war_v6_halfbody_style_transparent/{id}_war_face_icon_v6_cute50_source.png \
  --out assets/generals/face_icons/war_v6_halfbody_style_transparent/{id}_war_face_icon_v6_cute50.png
```
